# /craft:plan:feature

> **Feature planning: scaffold a spec, tests, and docs for a described feature**

---

## Synopsis

```bash
/craft:plan:feature <feature_description>
```

---

## Description

Feature planning with tests and docs scaffolded by default. Runs the prompt-refiner
by default (deliberation-entry command); pass `--no-refine` to skip. Pass `--no-tests`
or `--no-docs` to skip the auto-emitted test-plan/documentation sections.
