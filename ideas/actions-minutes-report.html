🔬Online-CI Research — does an external platform make sense?

Key correction found: since March 1, 2026, GitHub charges a $0.002/min "Actions cloud platform" fee for self-hosted runners in private repos (drawn from the included 3,000-min pool first; public repos stay free). The earlier proposal's "self-hosted = 0 pool minutes forever" claim is wrong post-March — still ~4× cheaper than hosted overage ($0.008/min) and Mac-fast, but no longer a free escape hatch.
